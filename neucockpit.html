Set up local document search

NeuCockpit is for people who need to revisit documents, specifications, project notes or source files and remember their contents better than their filenames. It searches folders you choose to index.

  1. Download the installer for your operating system and CPU architecture. Apple Silicon and ARM64 builds differ from Intel and x64 builds.
  2. Install and launch NeuCockpit. Let model setup finish before using local AI; initial downloads and optional account features can require internet access.
  3. Choose a folder containing files you are allowed to process and let indexing complete. Start with a small folder to check the results.
  4. Describe a document's contents, inspect the returned path and open the original file to verify the match. AI summaries need the same source check.

Read the guide to finding a file when you forgot its name. For setup help, email Zero-X support with your operating system and the step where you got stuck. Do not send private documents.

Indexing and document support

The indexing pipeline extracts readable content from supported files, creates local embeddings and stores a searchable index. Supported parsers include PDF, DOCX, PPTX, XLSX and common text and source-code files. A scanned image-only PDF, encrypted document or unsupported format may not produce searchable text. Media file views do not mean every image, audio clip or video can be understood by content.

New or edited files need the index to refresh before their latest contents can appear. Search quality depends on the text extracted, the query and the contents of your selected folders. Semantic search can return a related document that is not the one you intended.

Local search and optional online features

Local search uses BGE embeddings with a FAISS index. Local AI uses Qwen through llama.cpp, and metadata is kept in SQLite on your computer. Optional cloud or internet features have a separate data flow and may send submitted content to online providers. Choose the mode that fits your documents. Read the privacy policy.

Questions before installing

Does this replace Windows Search, Spotlight or Linux file tools?

NeuCockpit provides a separate semantic search interface for indexed folders. You can keep using your operating system's existing file tools.

Can I search a PDF by a topic instead of its name?

Yes, when the PDF contains readable text and its folder has finished indexing. Try a description of the passage or topic and check the original result. Scanned PDFs can need text extraction before their content is searchable.

Are all my folders indexed automatically?

Start by choosing the folders you want to search. A file outside the indexed scope will not be returned as though the app had read it. Check the indexing status when results are missing.

Can I use it offline?

Local search and local AI run on your computer once their required components are available. Downloads, sign-in and optional internet or cloud features require a connection.

Are AI answers guaranteed to be correct?

No. Retrieval and generated summaries can be incomplete or wrong. Open the source and verify important details before acting on them.

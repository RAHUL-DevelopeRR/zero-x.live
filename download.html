        Command line

        Installs the neuron command and its full-screen terminal UI. Pick one method.

        The npm and pip packages are available now.

        Windows (PowerShell)

        irm https://github.com/RAHUL-DevelopeRR/neuron-v2/releases/latest/download/install.ps1 | iex

        macOS and Linux

        curl -fsSL https://github.com/RAHUL-DevelopeRR/neuron-v2/releases/latest/download/install.sh | sh

        The install scripts download Neuron from its GitHub releases and work from the first public release. Until then, install with npm or pip.

        npm

        npm install -g @zero-x.live/neuron

        Needs Node.js. Downloads the native binary for your platform and checks its SHA-256.

        pip

        python -m pip install neuroncli

        Needs Python 3.9 or later. PyPI releases can trail npm; check with neuron --version.

        Then sign in once with neuron auth login and run neuron in a project. The quickstart has the details.

        Verify your download

        Every release publishes a .sha256 file for each binary and a SHA256SUMS list of all files.

        Compare the checksum of the file you downloaded with the one listed above:

        Windows (PowerShell)
        Get-FileHash .\neuron-windows-x64.exe -Algorithm SHA256
        macOS and Linux
        shasum -a 256 neuron-macos-arm64

        Release binaries also carry a GitHub build attestation that proves which workflow built them:

        gh attestation verify neuron-linux-x64 --repo RAHUL-DevelopeRR/neuron-v2

        The npm package checks the binary's SHA-256 itself before installing it. If a checksum does not match, do not run the file; tell us at support@zero-x.live.

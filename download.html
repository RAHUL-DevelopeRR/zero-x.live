        Command line

        Installs the neuron command and its full-screen terminal UI. Pick the command for your system.

        Neuron 7.0.0-alpha.1 is a GitHub pre-release. A pre-release is never marked as the latest release, so keep the version in the command.

        macOS and Linux

        curl -fsSL https://github.com/RAHUL-DevelopeRR/neuron-v2/releases/download/v7.0.0-alpha.1/install.sh | sh -s -- --version 7.0.0-alpha.1

        Windows (PowerShell 5.1 or 7)

        & ([scriptblock]::Create((irm https://github.com/RAHUL-DevelopeRR/neuron-v2/releases/download/v7.0.0-alpha.1/install.ps1))) -Version 7.0.0-alpha.1

        The installers download neuron and neuron-tui from GitHub Releases and verify their SHA-256 checksums. npm (@zero-x.live/neuron@next) comes once the alpha is published there; pip is not available for the alpha.

        Then sign in once with neuron login and run neuron in a project. The quickstart has the details.

        Verify your download

        Every release publishes a .sha256 file for each binary and a SHA256SUMS list of all files.

        Compare the checksum of the file you downloaded with the one listed above:

        Windows (PowerShell)
        Get-FileHash .\neuron-windows-x64.exe -Algorithm SHA256
        macOS and Linux
        shasum -a 256 neuron-macos-arm64

        Release binaries also carry a GitHub build attestation that proves which workflow built them:

        gh attestation verify neuron-linux-x64 --repo RAHUL-DevelopeRR/neuron-v2

        The install scripts check each binary's SHA-256 before installing it. If a checksum does not match, do not run the file; tell us at support@zero-x.live.

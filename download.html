Download Neuron

Neuron is an AI coding agent that works in your projects. Install the command line with one command, or download the release binaries below. Every file comes with a SHA-256 checksum. The desktop and mobile apps are coming soon; they are listed further down this page.

Command line

Installs the neuron command and its full-screen terminal UI. Pick your system in the menu: the Windows, macOS and Linux commands need nothing installed first, and npm and pip are there if you prefer them.

Neuron 7.0.0-alpha.5 is a GitHub pre-release, published on 3 November 2026. It adds a status bar under the prompt that shows the model, thinking level, folder and branch, permission mode and how full the context is.

Get Neuron
irm https://zero-x.live/install.ps1 | iex

Or read the documentation

  • Windows (PowerShell) irm https://zero-x.live/install.ps1 | iex
  • Windows (Command Prompt) powershell -ExecutionPolicy Bypass -NoProfile -Command "irm https://zero-x.live/install.ps1 | iex"
  • macOS / Linux curl -fsSL https://zero-x.live/install.sh | sh
  • npm npm install -g @zero-x.live/neuron
  • pip python -m pip install --pre neuroncli

The installers download neuron and neuron-tui from GitHub Releases and verify their SHA-256 checksums; on Windows, neuron-tui (more than 100 MB) is a second command that the installer prints. npm needs Node.js 22.14 or later and pip Python 3.9 or later; keep --pre while Neuron 7 is a pre-release. The install guide has the details and fixes for common errors.

Open a new terminal, run neuron login, then neuron in your project folder. The quickstart has the details.

Verify your download

Every release publishes a .sha256 file for each binary and a SHA256SUMS list of all files.

Compare the checksum of the file you downloaded with the one in the table above or in the release's .sha256 file:

Windows (PowerShell)
Get-FileHash .\neuron-windows-x64.exe -Algorithm SHA256
macOS and Linux
shasum -a 256 neuron-macos-arm64

Release binaries also carry a GitHub build attestation that proves which workflow built them:

gh attestation verify neuron-linux-x64 --repo RAHUL-DevelopeRR/neuron-v2

The install scripts check each binary's SHA-256 before installing it. If a checksum does not match, do not run the file; tell us at support@zero-x.live.

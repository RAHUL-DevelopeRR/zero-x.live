Neuron by Zero-X

The AI coding agent that lives in your terminal

Neuron reads your project, plans the change, edits files and runs your tests, and asks before it does anything you have not allowed. Sign in once to use hosted models from providers like Google Gemini and Groq on the Free plan, or bring your own API key.

Install on macOS and Linux

curl -fsSL https://github.com/RAHUL-DevelopeRR/neuron-v2/releases/download/v7.0.0-alpha.1/install.sh | sh -s -- --version 7.0.0-alpha.1

Installs neuron and neuron-tui to ~/.local/bin and checks their SHA-256 checksums. Linux needs glibc 2.35 or later (Ubuntu 22.04, Debian 12, Fedora 36 or newer).

Install on Windows with PowerShell

& ([scriptblock]::Create((irm https://github.com/RAHUL-DevelopeRR/neuron-v2/releases/download/v7.0.0-alpha.1/install.ps1))) -Version 7.0.0-alpha.1

Windows PowerShell 5.1 or PowerShell 7. Installs to %LOCALAPPDATA%\Programs\Neuron\bin; add -AddToPath at the end to put that folder on your user PATH.

Install with npm

Not yet. Once the alpha is published to npm, it will be npm install --global @zero-x.live/neuron@next (Node.js 22.14 or later). Without @next, npm installs the old 6.2.0 build, which is not supported.

Install with pip

Not available for the alpha. PyPI uploads are paused and the Python launcher will follow later. The neuroncli 6.2.4 package on PyPI is an old build and is not supported.

Build from source

git clone https://github.com/RAHUL-DevelopeRR/neuron-v2.git
cd neuron-v2/rust
cargo build --release -p rusty-claude-cli

Needs the Rust toolchain. The binary is target/release/neuron.

Get started

From install to first change in three steps

  1. Install

    curl -fsSL https://github.com/RAHUL-DevelopeRR/neuron-v2/releases/download/v7.0.0-alpha.1/install.sh | sh -s -- --version 7.0.0-alpha.1

    That is the macOS and Linux installer. On Windows, use the PowerShell command from the Windows tab above, or build from source.

  2. Sign in once

    neuron login

    Neuron prints a link, https://neuron.zero-x.live/device, and a short code, and opens the link in your browser when it can. Sign in with Google, GitHub or email, check that the code matches and approve it; the terminal continues on its own. No local port is opened, so this also works over SSH, in WSL and in containers. Your provider keys never leave Zero-X.

  3. Ask in your project

    cd path/to/your-project
neuron

    On a terminal, neuron opens the full-screen UI. Ask for something concrete, like “explain how requests are authenticated, then add a test for an expired token”. Switch models with /model, change what Neuron may do with /permissions and check today's limits with /usage.

What Neuron does

A senior pair programmer that runs your tools

Repo-aware agent loop

Explores the files that matter, makes a plan, edits code and checks the result with your tests or build before it reports back.

Real tools

Reads, writes and edits files, searches with glob and grep, runs shell or PowerShell commands, fetches web pages and keeps a task list for long jobs.

You stay in control

The default mode, workspace-write, edits files in your workspace and runs read-only commands; switch to read-only or danger-full-access with --permission-mode. Anything else needs your approval: allow once, allow for the session, deny, or deny with a note.

Full-screen terminal UI

On a terminal, neuron opens neuron-tui: streamed replies, tool calls with their output, a permission dialog, a model picker and a footer with model, git state, tokens and context. neuron --continue reopens your latest chat; neuron --no-tui keeps the line REPL.

MCP servers and subagents

Plug in Model Context Protocol servers for extra tools, and hand focused jobs like code search or review to subagents with their own context.

Headless and CI

Run one-shot tasks with neuron -p "…". Create an API key in the dashboard and set NEURON_TOKEN on servers without a browser.

Hosted models, no keys to manage

Sign in and Neuron routes through the Zero-X gateway. Provider keys stay on the server; Neuron keeps its login in the macOS Keychain or Windows Credential Manager, and on Linux in ~/.neuroncli/credentials.json, readable only by you.

Bring your own key

Prefer your own provider? Set OPENAI_API_KEY and OPENAI_BASE_URL for any OpenAI-compatible endpoint, or connect your own OpenRouter account.

Questions

Which providers see my code?

The files and messages Neuron includes in a request go to the provider serving the model you chose, such as Google Gemini, Groq, NVIDIA, OpenRouter or Cloudflare Workers AI through Zero-X, or the provider behind your own key. Free tiers of some providers may use prompts to improve their models. The Zero-X gateway records usage metadata (model, tokens, cost, latency) and is not designed to store prompt or response text. Details are in the privacy policy.

What do I get on the Free plan?

The Free plan allows 100 requests and 500K tokens per day on shared free model pools, with best-effort availability. Limits reset at 00:00 UTC. Pro and Max raise the limits and add paid-capacity models. See limits and pricing.

Does it run on Windows, macOS and Linux?

Yes. Release binaries cover Linux x64 and arm64 (glibc 2.35 or later: Ubuntu 22.04, Debian 12, Fedora 36 or newer), macOS on Apple silicon and Intel, and Windows x64; Windows on Arm runs the x64 build under emulation. On older Linux distributions, build from source with Cargo; musl-based Linux such as Alpine is not supported. The binaries are not code-signed or notarized. On Windows, Neuron can run PowerShell commands as well as shell commands.

Can I use Neuron without a Zero-X account?

Yes. Point it at your own OpenAI-compatible endpoint with OPENAI_API_KEY and OPENAI_BASE_URL. Signing in to Zero-X gives you the hosted models, the usage dashboard and plan limits.

Where is the source code?

Neuron is written in Rust and is MIT-licensed; its full-screen UI (neuron-tui) is derived from Freebuff and is Apache-2.0. The source and releases are on GitHub. Report bugs and request features there.

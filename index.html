What is Zero-X?
The project behind NeuCockpit.

Zero-X is the software project behind NeuCockpit, a local-first desktop application for semantic file and document search, built in Tamil Nadu, India.

Our focus is desktop tools for finding and working with files. NeuCockpit includes local search and AI, with optional online features.

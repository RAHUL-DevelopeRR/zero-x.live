Get started

From install to first change in three steps

  1. Install

    Get Neuron
    irm https://zero-x.live/install.ps1 | iex

    Or read the documentation

    • Windows (PowerShell) irm https://zero-x.live/install.ps1 | iex
    • Windows (Command Prompt) powershell -ExecutionPolicy Bypass -NoProfile -Command "irm https://zero-x.live/install.ps1 | iex"
    • macOS / Linux curl -fsSL https://zero-x.live/install.sh | sh
    • npm npm install -g @zero-x.live/neuron
    • pip python -m pip install --pre neuroncli

    Pick your system in the menu. The Windows, macOS and Linux commands need nothing installed first. Open a new terminal, run neuron login, then neuron in your project folder.

  2. Sign in once

    neuron login

    Neuron prints a link, https://neuron.zero-x.live/device, and a short code, and opens the link in your browser when it can. Sign in with Google, GitHub or email, check that the code matches and approve it; the terminal continues on its own. No local port is opened, so this also works over SSH, in WSL and in containers.

  3. Ask in your project

    cd path/to/your-project
neuron

    On a terminal, neuron opens the full-screen UI. Ask for something concrete, like “explain how requests are authenticated, then add a test for an expired token”. Switch models with /model, change what Neuron may do with /permissions and check today's limits with /usage.

What Neuron does

Reads, edits and tests in your repository

Repo-aware agent loop

Explores the files that matter, makes a plan, edits code and checks the result with your tests or build before it reports back.

Real tools

Reads, writes and edits files, searches with glob and grep, runs shell or PowerShell commands, fetches web pages and keeps a task list for long jobs.

You stay in control

The default mode, workspace-write, edits files in your workspace and runs read-only commands; switch to read-only or danger-full-access with --permission-mode. Anything else needs your approval: allow once, allow for the session, deny, or deny with a note.

Full-screen terminal UI

On a terminal, neuron opens neuron-tui: streamed replies, tool calls with their output, a permission dialog, a model picker and a footer with model, git state, tokens and context. neuron --continue reopens the latest chat for this folder; neuron --no-tui keeps the line REPL.

MCP servers and subagents

Plug in Model Context Protocol servers for extra tools, and hand focused jobs like code search or review to subagents with their own context.

Headless and CI

Run one-shot tasks with neuron -p "…". Create an API key in the dashboard and set NEURON_TOKEN on servers without a browser.

Hosted models, no keys to manage

Sign in and Neuron routes through the Zero-X gateway. Model keys stay on the server; Neuron keeps its login in the macOS Keychain or Windows Credential Manager, and on Linux in ~/.neuroncli/credentials.json, readable only by you.

Bring your own key

Prefer your own provider? Set OPENAI_API_KEY and OPENAI_BASE_URL for any OpenAI-compatible endpoint, or connect your own account with a supported provider.

Questions

What is an AI coding agent?

An AI coding agent uses a large language model (LLM) to work on your code the way you would in a terminal: it reads files, plans a change, edits them, runs your tests or build and reports what changed, asking before steps you have not allowed. Neuron is the coding agent Zero-X builds. Read how AI coding agents work.

Who sees my code?

The files and messages Neuron includes in a request go to the company that serves the model you chose through Zero-X, or to the provider behind your own key. Free tiers of some of these services may use prompts to improve their models. The Zero-X gateway records usage metadata (model, tokens, cost, latency) and is not designed to store prompt or response text. Every company that can receive a request is named in the privacy policy.

What do I get on the Free plan?

The Free plan allows 100 requests per day and 3M tokens every 5 hours on free models chosen for coding, with best-effort availability. The request limit resets at 00:00 UTC; tokens free up 5 hours after they are used. The paid plans (Athlete, Speed, Pro and Max) raise the limits and add Claude Sonnet 5.5 and Claude Opus 5.5. See limits and pricing.

Does it run on Windows, macOS and Linux?

Yes. Release binaries cover Linux x64 and arm64 (glibc 2.35 or later: Ubuntu 22.04, Debian 12, Fedora 36 or newer), macOS on Apple silicon and Intel, and Windows x64; Windows on Arm runs the x64 build under emulation. On older Linux distributions, build from source with Cargo (see install options); musl-based Linux such as Alpine is not supported. The binaries are not code-signed or notarized. On Windows, Neuron can run PowerShell commands as well as shell commands.

Can I use Neuron without a Zero-X account?

Yes. Point it at your own OpenAI-compatible endpoint with OPENAI_API_KEY and OPENAI_BASE_URL. Signing in to Zero-X gives you the hosted models, the usage dashboard and plan limits.

How does Neuron compare with Claude Code, Codex CLI and Aider?

All four are AI coding agents for the terminal. Neuron is MIT-licensed, starts free on hosted LLMs and is not tied to one model maker; it is also younger and still an alpha. Read the side-by-side comparison and what is free in Neuron.

Where is the source code?

Neuron is written in Rust and is MIT-licensed; its full-screen UI (neuron-tui) is derived from Freebuff and is Apache-2.0. The source and releases are on GitHub. Report bugs and request features there.

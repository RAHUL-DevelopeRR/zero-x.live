# Zero-X website design direction

Source: existing owner-supplied `Assets/zero-x/DESIGN.md`, selected by the user for this redesign. This transcribes that direction and records its application. It does not change the desktop application's brand.

## Supplied direction

- Light mode, prioritizing clarity and visibility.
- Primary green: `#0fff46`.
- Secondary green: `#0e8a23`.
- Warm tertiary: `#ffd3ab`.
- Neutral: `#6f7a6a`.
- Inter for headings, body, and labels.
- Moderate roundedness (2) and normal spacing (2).

## Design read

Reading this as: a desktop product website for professionals with documents to find, in a light, green, document-first visual language, dial ENERGY 2 / RHYTHM 3 / MOTION 1.

## Application and purpose

- Bright green marks the file-finding hook and main download action; dark text preserves contrast.
- Small green text uses `#07561c` where supplied `#0e8a23` fails AA on white.
- Ink `#172019` and supporting text `#485448` make explanations readable on white and `#f4f6f1` surfaces.
- Supplied neutral defines control borders. The warm tertiary is reserved, not needed on these pages.
- Inter follows supplied direction; system sans-serif is the fallback when the font service is unavailable.
- Left-aligned questions and document-path labels form a repeated identity motif connected to file retrieval.
- Hero pairs the actual problem with real app evidence; downloads are file rows rather than pricing cards; setup is a usable document.
- Spacing changes with the story: compact requirements, broader evidence, short personal invitation.
- Radius is 6px for controls and 14px for media, matching moderate roundedness.
- Borders separate documents and downloads. No glass, glow, generic icons, background patterns, floating elements, or fictional counters.
- Web motion is interaction feedback only. Campaign plays on request and is labelled motion graphics.
- Real screenshots use disclosed demo documents, with no private filenames. Never present a synthetic screenshot as the app.
- Fixed light theme follows supplied direction. Existing dark desktop media is not another website theme.

## Content and interactions

- Main action downloads actual platform/architecture installer.
- Assisted setup emails existing founder mailbox `rahul@zero-x.live`.
- Account access retains the actual dashboard destination; downloads need no marketing-site signup.
- Disclose automatic common-folder indexing, extra-folder controls, model behavior, and document limitations.
- No fictional reviews, users, speed claims, or visitor estimates.
- Feedback opens an email draft and says it still needs sending; no collection backend implied.

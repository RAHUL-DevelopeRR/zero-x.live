What is Zero-X?

Zero-X builds Neuron, an AI coding agent that runs in your terminal, and NeuCockpit, a local-first AI desktop application for semantic file and document search. The project is built in Tamil Nadu, India. Zero-X also runs the gateway at zero-x.live that Neuron signs in to for hosted models.

The name is also written Zero X or ZeroX. This Zero-X is not connected with the Infinix ZERO X phones or the Zero X electric motorcycle.

What Neuron does

Neuron reads your project, edits files and runs commands, and asks before it does anything your permission mode does not allow. Sign in once with neuron login to use hosted models through the Zero-X gateway, or bring your own provider key.

The current release, 7.0.0-alpha.1, is a GitHub pre-release for Linux (x64 and arm64), macOS (Apple silicon and Intel) and Windows x64. Neuron is MIT-licensed; its full-screen terminal UI is derived from Freebuff and is Apache-2.0.

Install Neuron, read the documentation, compare plans or learn how AI coding agents work.

What NeuCockpit does

NeuCockpit helps you find a document when you remember what it contains but have forgotten its name. Choose a folder, let it index supported content, describe what you remember and inspect the matching file. Local AI can summarize documents and help answer questions; the original file remains the source to verify.

Installers are available for Windows, macOS and Linux. Local indexing and local AI run on your computer. Optional account, internet and cloud services require a connection and have separate privacy considerations.

Read NeuCockpit's features, setup steps and limitations or follow a practical file-search guide.

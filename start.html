From installation to a result.

  1. Install the right build

    Choose your operating system and CPU architecture on the download page. Read its requirements, run the installer, and launch NeuCockpit. If your operating system blocks the package, contact Rahul with the exact warning before deciding how to proceed.

  2. Check the index and add a folder

    The app can index common folders automatically. Check its indexing status, then use Add Folder to include a location you want to test. Start with a small folder of readable documents. Wait for indexing to finish; use Re-index when you need to refresh it.

  3. Describe the file you remember

    Type a phrase about the document’s contents in the search panel. Use a topic from your real work, then review the matching filenames and paths. On Windows, Shift + Space is the default panel shortcut. On macOS and Linux, use the tray or menu entry.

  4. Open it and check the answer

    Open the result in its usual application. If it is the right document, try a summary or question in MemoryOS. Check the output against the source. Leave internet mode off to test the local workflow.

No useful matches? Check that the folder finished indexing and the document contains extractable text. Try another description. AI not ready? Check the model status in the app and share the exact error with Rahul. See document limitations.

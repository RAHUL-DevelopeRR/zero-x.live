Quickstart

  1. Install: on macOS and Linux, curl -fsSL https://github.com/RAHUL-DevelopeRR/neuron-v2/releases/download/v7.0.0-alpha.1/install.sh | sh -s -- --version 7.0.0-alpha.1; on Windows (PowerShell 5.1 or 7), & ([scriptblock]::Create((irm https://github.com/RAHUL-DevelopeRR/neuron-v2/releases/download/v7.0.0-alpha.1/install.ps1))) -Version 7.0.0-alpha.1. npm (@zero-x.live/neuron@next) comes once the alpha is published there; pip is not available for the alpha. See all install options.
  2. Sign in: neuron login prints https://neuron.zero-x.live/device and a short code. Open it in any browser, sign in, check the code and choose Approve. The code expires after 10 minutes.
  3. Run neuron inside a project; on a terminal it opens the full-screen UI. The UI cannot trust a folder yet: run neuron --no-tui there once and press 1, or add the folder to trustedRoots in ~/.neuron/settings.json. Until then the folder's own settings, hooks and MCP servers are ignored.
curl -fsSL https://github.com/RAHUL-DevelopeRR/neuron-v2/releases/download/v7.0.0-alpha.1/install.sh | sh -s -- --version 7.0.0-alpha.1
neuron login
cd path/to/project
neuron

Check the result with neuron auth status. If something fails, run neuron doctor.

API reference

The gateway speaks the OpenAI Chat Completions protocol. Base URL: https://zero-x.live/v1. Authenticate with Authorization: Bearer <token>, where the token is an API key from the dashboard or a CLI session.

GET /v1/models

Lists the catalog. Authentication is optional; available is computed for your plan (anonymous callers see the Free plan).

curl https://zero-x.live/v1/models -H "Authorization: Bearer $NEURON_TOKEN"
{
  "object": "list",
  "data": [{
    "id": "gemini/gemini-2.5-flash",
    "object": "model",
    "created": 0,
    "owned_by": "gemini",
    "display_name": "Gemini 2.5 Flash",
    "context_window": 1048576,
    "context_length": 1048576,
    "max_output_tokens": 65536,
    "capabilities": { "tools": true, "streaming": true, "vision": true, "reasoning": true },
    "reasoning_efforts": ["none", "low", "medium", "high"],
    "tiers": ["free"],
    "available": true,
    "unavailable_reason": null,
    "pricing": null,
    "status": "available",
    "available_again_at": null,
    "checked_at": "2026-10-24T13:53:52.473Z"
  }]
}

unavailable_reason is null, upgrade_required, region_unavailable or not_configured. pricing is the paid-capacity price per million tokens, or null for free-only models. status is available, degraded, busy or blurred; a blurred model is temporarily unavailable until available_again_at. GET /v1/models/status returns the same availability fields for polling. The list includes the pseudo-model auto.

POST /v1/chat/completions

Standard OpenAI request body. model may be auto. Set "stream": true for server-sent events ending with data: [DONE]; streamed tool_calls deltas always include index.

curl https://zero-x.live/v1/chat/completions \
  -H "Authorization: Bearer $NEURON_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model":"auto","messages":[{"role":"user","content":"Explain this stack trace"}]}'

Response headers:

  • x-request-id: quote it when you contact support.
  • x-neuron-model: the model that served the request (useful with auto).
  • x-neuron-plan: your plan.
  • x-neuron-quota-remaining-requests, x-neuron-quota-remaining-tokens: what is left today.

Any OpenAI-compatible SDK works; set its base URL to https://zero-x.live/v1 and its API key to your nzx_ key.

Error codes

Errors use the OpenAI shape, with extra fields when they help:

{ "error": { "message": "…", "type": "insufficient_quota", "code": "insufficient_quota",
  "param": null, "request_id": "…", "upgrade_url": "https://zero-x.live/pricing",
  "resets_at": "2026-10-17T00:00:00Z" } }

Limits

PlanRequests / dayTokens / dayRequests / minConcurrentPools
Free100500,000102Free
Pro2,00010,000,000304Free and paid
Max10,00050,000,000608Free and paid
  • Daily caps reset at 00:00 UTC. Tokens are prompt plus completion tokens.
  • Every free pool also has a global daily budget shared by all users; when it is spent you get capacity_exhausted even if your own cap has room.
  • Groq's free tier allows about 8,000 tokens per minute, so large prompts go to models with more headroom.
  • Paid-capacity requests cost credits at the upstream price plus 25%. Free-pool requests cost no credits.

API keys

  • Create keys in the dashboard. A key starts with nzx_ and is shown once; Zero-X stores only a hash.
  • You can have up to 10 active keys. Revoke a key at any time; it stops working immediately.
  • Keys can call /v1/* and read GET /api/account and GET /api/usage. They cannot create or revoke keys, end sessions or change billing.
  • Usage made with a key counts toward your account's plan limits.
  • Keys are for your own scripts and CI. Sharing or reselling access is not allowed under the Terms of Service.

Billing FAQ

How am I billed?

Pro and Max are monthly subscriptions in USD or INR, processed by Razorpay. They renew automatically until you cancel. Each successful renewal adds the plan's included credits to your balance.

Where are my invoices?

Payment history and invoice links are on the Billing tab of the dashboard. Razorpay also emails a receipt.

What if a renewal payment fails?

Razorpay retries the payment and the dashboard shows a payment issue. If the subscription ends unpaid, your account returns to the Free plan.

How do I cancel or get a refund?

Cancel from the Billing tab; access continues until the end of the paid period. Refunds follow the cancellation and refund policy.

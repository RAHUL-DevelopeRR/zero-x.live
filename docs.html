Neuron CLI and Zero-X API docs

Everything you need to install Neuron, sign in, configure it, and call the OpenAI-compatible gateway directly.

These docs cover Neuron 7.0.0-alpha.5, a GitHub pre-release published on 7 November 2026. It adds a status bar under the prompt in the full-screen UI: the model, thinking level, folder and branch, permission mode and how full the context is. The full reference is the usage guide; see the changelog for known limitations.

Install

Neuron 7.0.0-alpha.5 runs on Windows x64 (Windows on Arm under emulation), macOS on Apple silicon and Intel, and Linux x64 and arm64 with glibc 2.35 or later (Ubuntu 22.04, Debian 12, Fedora 36 or newer). Pick your system in the menu and paste the command into a terminal.

Get Neuron
irm https://zero-x.live/install.ps1 | iex

Something went wrong? See Troubleshooting

  • Windows (PowerShell) irm https://zero-x.live/install.ps1 | iex
  • Windows (Command Prompt) powershell -ExecutionPolicy Bypass -NoProfile -Command "irm https://zero-x.live/install.ps1 | iex"
  • macOS / Linux curl -fsSL https://zero-x.live/install.sh | sh
  • npm npm install -g @zero-x.live/neuron
  • pip python -m pip install --pre neuroncli

One-line installers

  • Windows PowerShell (Windows PowerShell 5.1, the default on Windows 10 and 11, or PowerShell 7): irm https://zero-x.live/install.ps1 | iex. It works with Windows' default script settings, because no script file is run. It installs neuron.exe to %LOCALAPPDATA%\Programs\Neuron\bin, adds that folder to your user PATH and then prints the command that adds the full-screen UI, neuron-tui.exe, as a second step.
  • Windows Command Prompt (cmd.exe): powershell -ExecutionPolicy Bypass -NoProfile -Command "irm https://zero-x.live/install.ps1 | iex" runs the same installer through PowerShell.
  • macOS and Linux (sh, bash or zsh): curl -fsSL https://zero-x.live/install.sh | sh installs neuron and neuron-tui to ~/.local/bin and tells you if that folder is not on your PATH. musl-based Linux such as Alpine is not supported.

The installers download the binaries of this release from GitHub Releases and verify their SHA-256 checksums. The full-screen UI (neuron-tui) is a download of more than 100 MB, and this release's Windows installer shows no progress while it downloads it, so on Windows the one-liner installs neuron first (it uses its line REPL until the UI is there). To add the UI, run $env:NEURON_NO_TUI = '0'; irm https://zero-x.live/install.ps1 | iex in PowerShell; on a slow connection it can take several minutes. On macOS and Linux the installer adds the UI straight away; set NEURON_NO_TUI=1 first to install only neuron. The binaries are not code-signed (Windows) or notarized (macOS).

Other ways to install

  • npm (needs Node.js 22.14 or later): npm install -g @zero-x.live/neuron. Run it again to upgrade. On Windows, if PowerShell says “running scripts is disabled on this system”, use npm.cmd install -g @zero-x.live/neuron and run neuron.cmd, or use the PowerShell command above.
  • pip (needs Python 3.9 or later): python -m pip install --pre neuroncli. Keep --pre while Neuron 7 is a pre-release, or pip installs the old, unsupported 6.2.4. To upgrade: python -m pip install --upgrade --pre neuroncli.
  • This release straight from GitHub, without zero-x.live:
    Windows PowerShell
    & ([scriptblock]::Create((irm https://github.com/RAHUL-DevelopeRR/neuron-v2/releases/download/v7.0.0-alpha.5/install.ps1))) -Version 7.0.0-alpha.5 -AddToPath
    macOS or Linux terminal
    curl -fsSL https://github.com/RAHUL-DevelopeRR/neuron-v2/releases/download/v7.0.0-alpha.5/install.sh | sh -s -- --version 7.0.0-alpha.5
    A pre-release is never GitHub's latest release, so these name the version.

After installing

Open a new terminal, run neuron login, then neuron in your project folder. The PATH change only reaches terminals opened after the install. Check the install with neuron --version, and run neuron doctor if something does not work.

Troubleshooting

“npm.ps1 cannot be loaded because running scripts is disabled on this system” (or the same for neuron.ps1)
Windows PowerShell's default setting blocks the .ps1 launchers that npm installs. Use the PowerShell one-liner above, which runs no script file. To keep npm, run npm.cmd install -g @zero-x.live/neuron and start Neuron with neuron.cmd, or allow signed and local scripts for your account with Set-ExecutionPolicy -Scope CurrentUser RemoteSigned.
“Python was not found; run without arguments to install from the Microsoft Store”
Python is not installed: on Windows, python is a shortcut to the Microsoft Store until it is. Use the PowerShell one-liner above, or install Python 3.9 or later from python.org, open a new terminal and run the pip command again.
“npm is not recognized as the name of a cmdlet” or “'npm' is not recognized as an internal or external command”
Node.js is not installed. Use the one-liner for your system instead; it needs neither Node.js nor Python.
“neuron is not recognized” or “neuron: command not found” right after installing
Open a new terminal: the PATH change does not reach terminals that were already open. On macOS and Linux, add ~/.local/bin to your PATH if the installer said it is missing.
“'irm' is not recognized as an internal or external command, operable program or batch file.”
The PowerShell command was pasted into Command Prompt (cmd.exe), which has no irm. Choose Windows (Command Prompt) in the menu and use that command, or open PowerShell from the Start menu and paste the first one there.
“'curl' is not recognized” or “'|' is not recognized” on Windows
The macOS and Linux command was pasted into a Windows terminal. Choose Windows (PowerShell) or Windows (Command Prompt) in the menu.
“& was unexpected at this time.”
The GitHub PowerShell command (the one that starts with &) was pasted into Command Prompt. Use the Windows (Command Prompt) command from the menu instead.
The install stays on “installing the full-screen UI (neuron-tui.exe) ...” for minutes
It is downloading the full-screen UI, more than 100 MB, and shows no progress while it does; Windows may also scan the new program the first time it runs. Let it finish. neuron works without the UI: the one-liner installs it on its own (or set $env:NEURON_NO_TUI = '1' before the GitHub command), and you can add the UI later with $env:NEURON_NO_TUI = '0'; irm https://zero-x.live/install.ps1 | iex in a new terminal.
“could not look up the latest Neuron release”
The GitHub installer was run without a version, and a pre-release is never GitHub's latest release. Use irm https://zero-x.live/install.ps1 | iex or curl -fsSL https://zero-x.live/install.sh | sh, which name the version for you.

Quickstart

  1. Install Neuron with the command for your system from Install, then open a new terminal.
  2. Sign in: neuron login prints https://neuron.zero-x.live/device and a short code. Open it in any browser, sign in, check the code and choose Approve. The code expires after 10 minutes.
  3. Run neuron inside a project; on a terminal it opens the full-screen UI. The UI cannot trust a folder yet: run neuron --no-tui there once and press 1, or add the folder to trustedRoots in ~/.neuron/settings.json. Until then the folder's own settings, hooks and MCP servers are ignored. Security and trust explains what trusting a folder allows.
After installing
neuron login
cd path/to/project
neuron

Check the result with neuron auth status. If something fails, run neuron doctor.

API reference

The gateway speaks the OpenAI Chat Completions protocol. Base URL: https://zero-x.live/v1. Authenticate with Authorization: Bearer <token>, where the token is an API key from the dashboard or a CLI session.

GET /v1/models

Lists the catalog, one entry per model. Authentication is optional; available and context_window are computed for your plan (anonymous callers see the Free plan).

curl https://zero-x.live/v1/models -H "Authorization: Bearer $NEURON_TOKEN"
{
  "object": "list",
  "data": [{
    "id": "openai/gpt-oss-120b",
    "object": "model",
    "created": 0,
    "owned_by": "openai",
    "display_name": "GPT-OSS 120B",
    "maker": "openai",
    "maker_name": "OpenAI",
    "family": "openai/gpt-oss-120b",
    "context_window": 8000,
    "context_length": 8000,
    "native_context_window": 131072,
    "max_output_tokens": 8000,
    "capabilities": { "tools": true, "streaming": true, "vision": false, "reasoning": true },
    "reasoning_efforts": ["low", "medium", "high"],
    "tiers": ["free"],
    "available": true,
    "unavailable_reason": null,
    "pricing": null,
    "status": "available",
    "available_again_at": null,
    "checked_at": "2026-10-24T13:53:52.473Z"
  }]
}

unavailable_reason is null, upgrade_required, region_unavailable, policy_restricted or not_configured. pricing is the paid-capacity price per million tokens (input_per_mtok_usd, output_per_mtok_usd, and for Claude cache_read_per_mtok_usd and cache_write_per_mtok_usd), or null for free-only models. Claude Sonnet 5.5 (anthropic/claude-sonnet-5-5) and Claude Opus 5.5 (anthropic/claude-opus-5-5) are paid models: the paid plans can choose them and are billed from credits, Free sees them with upgrade_required, and auto never picks them. context_window is what you can send on your plan; native_context_window is the model's own maximum (some free models take smaller requests on the Free plan). maker names the company that made the model. status comes from the gateway's health checker: available, degraded (slower than usual), busy, unavailable (until available_again_at; older clients may see blurred) or unknown (nobody has checked it lately). GET /v1/models/status returns the same availability fields, with checked_at, for polling every 30 seconds. The list includes the pseudo-model auto.

POST /v1/chat/completions

Standard OpenAI request body. model may be auto. Set "stream": true for server-sent events ending with data: [DONE]; streamed tool_calls deltas always include index.

curl https://zero-x.live/v1/chat/completions \
  -H "Authorization: Bearer $NEURON_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model":"auto","messages":[{"role":"user","content":"Explain this stack trace"}]}'

Response headers:

  • x-request-id: quote it when you contact support.
  • x-neuron-model: the model that served the request (useful with auto).
  • x-neuron-plan: your plan.
  • x-neuron-quota-remaining-requests, x-neuron-quota-remaining-tokens: what is left today.

Any OpenAI-compatible SDK works; set its base URL to https://zero-x.live/v1 and its API key to your nzx_ key.

{ "error": { "message": "…", "type": "insufficient_quota", "code": "insufficient_quota",

Limits

PlanRequests / dayTokensRequests / minConcurrentPools
Free1003,000,000 per 5 hours102Free
Athlete3006,000,000 per day152Free and paid
Speed1,0008,000,000 per day203Free and paid
Pro2,00010,000,000 per day304Free and paid
Max10,00050,000,000 per day608Free and paid

Tokens count input plus output on every model call. Cached input, the part of the conversation the model has already seen, counts at 10%.

  • Daily caps reset at 00:00 UTC.
  • Free counts tokens over a rolling 5-hour window: each request's tokens count for 5 hours from when it started, and a running request counts with what it reserved (its prompt plus up to 1,024 output tokens) until it finishes. A request that would take the window past 3,000,000 tokens gets insufficient_quota with resets_at and Retry-After set to when enough of the window frees up; a single request larger than the whole window gets neither, since waiting does not make it fit. GET /api/account reports it as usage_window.
  • Every free pool also has a global daily budget shared by all users; when it is spent you get capacity_exhausted even if your own cap has room.
  • Some free models take small requests only (about 8,000 tokens), so auto sends large prompts to models with more headroom.
  • Claude Haiku 5.5 is included on every plan at no charge: up to 10M tokens a month per account, counted from the first of the month (UTC) and inside the plan's own limits. Choose it with model: "claude-haiku-5-5"; auto never picks it. When the allowance is used up the request returns insufficient_quota with resets_at and Retry-After set to the first of next month, without an upgrade_url, and every other model keeps working. Responses to Haiku requests carry x-neuron-quota-month-remaining-tokens, and GET /api/account lists the month's tokens in usage_month.
  • Paid-capacity requests cost credits at the upstream price plus 25%. Free-pool requests cost no credits.

API keys

  • Create keys in the dashboard. A key starts with nzx_ and is shown once; Zero-X stores only a hash.
  • You can have up to 10 active keys. Revoke a key at any time; it stops working immediately.
  • Keys can call /v1/* and read GET /api/account and GET /api/usage. They cannot create or revoke keys, end sessions or change billing.
  • Usage made with a key counts toward your account's plan limits.
  • Keys are for your own scripts and CI. Sharing or reselling access is not allowed under the Terms of Service.

Billing FAQ

How am I billed?

The paid plans (Athlete, Speed, Pro and Max) are monthly subscriptions in USD or INR, processed by Razorpay. They renew automatically until you cancel. Each successful renewal adds the plan's included credits to your balance.

Where are my invoices?

Payment history and invoice links are on the Billing tab of the dashboard. Razorpay may also email you a receipt.

What if a renewal payment fails?

Razorpay retries the payment and the dashboard shows a payment issue. If the subscription ends unpaid, your account returns to the Free plan.

Is GST charged?

No. The price shown is the price you pay. For a card in another currency your bank may add its own conversion or card fee.

How do I cancel or get a refund?

Cancel from the Billing tab; access continues until the end of the paid period. Refunds follow the cancellation and refund policy.

Data and privacy

  • Each request Neuron sends through Zero-X (your message, history, and the files or command output it included) goes to the model provider that serves it. The gateway stores usage metadata only, not the text of prompts or responses, and replaces credentials it recognises with placeholders first.
  • Free tiers of some providers may keep requests, let people review them or use them to improve their models. Your own provider key sends requests straight to that provider.
  • The data flow, the list of companies that receive your data, retention periods and how to ask for a copy or deletion are on Data and subprocessors. The binding statement is the privacy policy; what Neuron does on your computer is on Security and trust.

Help and support

  • Inside Neuron, run /doctor to check your setup and connection, and neuron auth status to see which credential is in use.
  • Email support@zero-x.live from your account address. Include the x-request-id of a failed request and the output of neuron --version. We reply within 2 business days.
  • Security problems: see reporting a security problem.
  • Installers, install commands and checksums: download Neuron. Release notes: what's new.
  • Plans, usage and API keys: the dashboard. Billing questions: the cancellation and refund policy or the contact page.

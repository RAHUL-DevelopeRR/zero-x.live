# Search audit and implementation — 3 October 2026

## Search evidence and the ranking problem

The verified Google Search Console property is `sc-domain:zero-x.live`. Its 3-month
report for 30 June–29 September 2026 shows 11 clicks, 685 impressions, 1.6% CTR and
average position 24.7. The visible `zero x` query row has 155 impressions and one
click. The average position is property-wide; it is not the position for that query
and neither number predicts today's ranking.

The owner's Google screenshot for `zero x` shows an Infinix phone result and a general
AI Overview explaining that the name refers to several things. It also shows a
Zero-X Cloud knowledge card. This is chiefly a brand-disambiguation and authority
problem, not a missing meta-tag problem. Users looking specifically for NeuCockpit
should be able to find the site for product/task queries such as “NeuCockpit local AI
file search” and “search local documents by meaning.” There is no reliable on-page
change that can guarantee first place for the broad phrase `zero x`.

The Pages report was last updated 21 September: 3 indexed URLs and 7 exclusions.
Google listed 3 canonical alternatives and 2 redirects, which are expected outcomes.
Two old 404s were checked and kept as 404s: a direct source-file path on the dashboard
subdomain and `/neuroncli`. Neither is a real public page with a suitable replacement.
The product homepage `https://neuron.zero-x.live/` was indexed.

## Remaining work to rank for the broad brand query

Search ranking depends on matching user intent and evidence of trust and authority.
The domain's Links report showed only two external linking sites in the earlier
snapshot. Improve this by earning useful references, not buying links:

1. Keep “ZeroX” consistently connected to “NeuCockpit” and the product's specific job
   in public company profiles, the official GitHub README, release notes and real demo
   material.
2. Publish a few detailed tutorials based on actual supported workflows, such as
   searching a folder by remembered content and checking a matching passage. Avoid
   making many near-duplicate keyword pages.
3. Ask real users (with permission) for specific workflow feedback and publish only
   verifiable examples. Do not invent reviews, outcomes, customer logos or speed claims.
4. Earn links by contributing relevant technical explanations to communities and
   directories that accept product resources. Do not post repetitive promotional links.
5. Review Search Console monthly. Separate `zero x`, `zerox`, `neucockpit` and task
   queries; compare impressions, clicks, CTR and landing pages over at least several
   weeks. A new video page first needs to be indexed and perform in Search before its
   video can be considered for video indexing.

## Architecture and free measurement

The existing static site, Cloudflare Worker and public sitemap are enough for this
content. Keep Search Console as the source for Google query/crawl data and PageSpeed
Insights for controlled performance checks. Avoid adding a framework, public database
dependency, paid SEO service, bought backlinks or keyword-page generator for this work.

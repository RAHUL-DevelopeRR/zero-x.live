# Search audit and implementation, 3 October 2026

## Baseline from the owner's Google Search Console

The verified domain property is `sc-domain:zero-x.live`.
The 3-month performance report shown today covers 30 June through 29 September 2026:
11 clicks, 685 impressions, 1.6% CTR, average position 24.7. The visible `zero x`
query row has 155 impressions and one click. These are property-wide report figures,
not a ranking promise or an October 3 live position measurement.

Page indexing's last update is 21 September: 3 indexed URLs and 7 exclusions.
Canonical alternatives and redirected URLs are normal exclusions. Two old 404 URLs
need inspection before deciding whether any redirect is appropriate. Direct URL
Inspection confirms `https://neuron.zero-x.live/` is indexed.

## Implemented

- Permanent server redirects for apex homepage, index.html and legacy product aliases.
  API requests are preserved; redirects retain query parameters. The public canonical
  pages are the www homepage and the neuron subdomain homepage.
- Sitemap uses those canonical URLs and the new guide, with actual modification dates.
- Organization, WebSite and WebPage graphs identify ZeroX and its existing alternate
  names. The product's own subdomain declares NeuCockpit by ZeroX as its site name.
- Product software markup uses an existing screenshot and accurate OS names. Removed
  unverified minimum OS versions and founding date. No invented rating/review/offer is
  used; Google software-app rich-result eligibility is not claimed.
- Visible product H1 names the app and its task. Home text connects ZeroX to NeuCockpit.
- HTML product links target the canonical product before JavaScript runs.
- Existing square 256px favicon selected for search discovery; no new logo generated.
- Authentication scripts deferred in order; no-JavaScript fallback reveals page text.
- Private dashboard and API responses carry noindex; dashboard has a matching meta tag.
- A practical, internally linked guide explains searching indexed contents, checking the
  source and handling missed documents. Examples are explicitly illustrative.

## Architecture

Retain static HTML/CSS served through the current Cloudflare Worker. Public content
does not require a framework, database lookup or login to render. The free Search
Console domain property supplies query/impression/crawl data. Supabase continues to
store accounts separately; SEO does not add public access to that data. No paid SEO
service, backlink purchase or keyword-page generator is necessary for these fixes.

## Verification and follow-up

`node neuroncli/auth-server/check-seo.mjs --live` checks live status, metadata,
canonical redirects, dashboard noindex and real 404 behavior. Existing Worker checks
cover authentication and database regressions. Desktop/mobile browser inspection and
Search Console live tests follow deployment. Request indexing and submit the sitemap
only after public content is verified. Search Console reports lag; judge results over
weeks, separating `zero x`, `zerox`, `neucockpit`, and task-specific query groups.

To build authority: publish actual workflow demonstrations and earned user case studies,
link the official product URL from controlled GitHub/social profiles, and contribute to
relevant communities under their promotion rules. A vague shared brand query competes
with phones, cloud products and other entities. Better relevance and authority can help;
no on-page change can guarantee first place.

What is an AI coding agent?

A guide by Zero-X, the team behind Neuron. Published 24 October 2026.

An AI coding agent is a program that uses a large language model to work on a codebase the way a developer does at a terminal. It reads files, decides what to change, edits them, runs commands such as your tests or build, looks at the result and repeats until the task is done or it needs your decision.

This guide explains how that loop works, what an agent should be allowed to do, where your code goes and which tasks suit an agent. The examples use Neuron, the open-source coding agent Zero-X builds for macOS, Linux and Windows.

Coding agents, autocomplete and chat assistants

Three kinds of AI developer tools are often grouped together:

  • Autocomplete suggests the next lines while you type in an editor. You accept or reject each suggestion.
  • A chat assistant answers questions and writes snippets. You copy the code into your project and run it yourself.
  • A coding agent acts on the project. It has tools to read and change files and to run commands, so it can take a task from finding the relevant code to passing tests, and then show you what it did.

The difference is who closes the loop. With autocomplete and chat, you run the code and bring the errors back. An agent runs the check itself, reads the failure and tries again.

How the agent loop works

  1. Explore. The agent searches the repository, for example with glob and grep, and reads the files that matter for your request instead of the whole project.

  2. Plan. It decides what to change. For longer jobs Neuron keeps a task list so each step stays visible.

  3. Edit. It writes new files or edits existing ones.

  4. Check. It runs your tests, build or linter, reads the output and fixes what failed.

  5. Report. It tells you what changed and why, so you can review the diff before you commit.

Each pass through the loop is a model request plus the tool calls it makes. A small fix may take a few passes and a larger change takes more, which is why daily request and token limits matter.

What the agent may do without asking

An agent that can run commands needs clear limits. Neuron has three permission modes:

  • read-only only reads and searches. It is a safe way to start in a repository you do not know yet.
  • workspace-write is the default.
  • danger-full-access applies only when you choose it with --permission-mode.

When a tool call needs approval, Neuron asks you: allow once, allow for the session, deny, or deny with a note. Every shell line is classified as a whole. Neuron also ignores a folder's own settings, hooks and MCP servers until you trust that folder.

Whichever agent you use, start from a git repository with a clean working tree. Every change the agent makes is then a diff you can review, keep or discard.

Which model runs it, and who sees your code

The agent is the loop and its tools; the model decides each step. Neuron can use:

  • Hosted models through Zero-X after neuron login, from providers including Google Gemini, Groq, NVIDIA, OpenRouter and Cloudflare Workers AI. Choose auto and Neuron picks a tool-capable model whose context window fits the request. See the current model list.
  • Your own provider. Set OPENAI_API_KEY and OPENAI_BASE_URL for any OpenAI-compatible endpoint, or connect your own OpenRouter account.

The files and messages an agent includes in a request go to the provider serving the model. Free tiers of some providers may use prompts to improve their models. The Zero-X gateway records usage metadata (model, tokens, cost, latency) and is not designed to store prompt or response text. Read the privacy policy before you point an agent at code you cannot share.

Good first tasks

Agents do best with a concrete request and a way to check the result. A few to try:

  • Explain how requests are authenticated in this repo.
  • Add a test for an expired token and fix whatever fails.
  • Run the test suite and summarise the failures.
  • Rename this function everywhere and update its callers.
  • Document the configuration options in the README.

A vague goal such as "improve the code" gives the agent nothing to verify. Name the files, the behaviour you expect and the command that proves it works.

Limits to keep in mind

  • Models can be wrong and sound certain. Review the diff and run the checks yourself before you merge.
  • A model sees only what fits in its context window, and long sessions fill it. In Neuron's line REPL, /compact shrinks a long session.
  • Free hosted models come from shared pools with best-effort availability. Neuron's Free plan allows 100 requests and 500K tokens a day; Pro and Max raise the limits.
  • Neuron 7.0.0-alpha.2 is an alpha, so expect rough edges and read the known limitations. The binaries are not code-signed (Windows) or notarized (macOS).

Try a coding agent in your terminal

Neuron installs with one command on macOS, Linux and Windows.

macOS and Linux
curl -fsSL https://github.com/RAHUL-DevelopeRR/neuron-v2/releases/download/v7.0.0-alpha.2/install.sh | sh -s -- --version 7.0.0-alpha.2
Windows (PowerShell)
& ([scriptblock]::Create((irm https://github.com/RAHUL-DevelopeRR/neuron-v2/releases/download/v7.0.0-alpha.2/install.ps1))) -Version 7.0.0-alpha.2

Then sign in once and start Neuron in a project:

First run
neuron login
cd path/to/your-project
neuron

neuron login shows a short code to approve at neuron.zero-x.live/device. For CI, create an API key in the dashboard and run Neuron headless with neuron -p. The quickstart covers folder trust, models and commands.

Questions

Is a coding agent the same as an AI agent?

A coding agent is one kind of AI agent. An AI agent is any program where a model chooses actions and uses tools toward a goal. A coding agent's tools are for software work: reading and editing files, searching code and running commands.

Is Neuron free?

Neuron is open source under the MIT licence. The Zero-X Free plan gives you hosted models with daily limits at no cost, or you can use your own API key. Pro and Max raise the limits.

Does Neuron work on Windows?

Yes. A Windows x64 build installs with PowerShell, and Neuron can run PowerShell commands as well as shell commands. Windows on Arm runs the x64 build under emulation.

Can I run a coding agent in CI?

Yes. Create an API key in the Zero-X dashboard, store it as a CI secret in NEURON_TOKEN and run neuron -p with your task. Never commit the key.

Zero-X / Neuron compared

A free, open-source alternative to Claude Code

By Zero-X, the team behind Neuron. Checked against each project's own pages on 5 November 2026.

Claude Code, OpenAI Codex CLI, Aider and Neuron are all AI coding agents that run in a terminal: they read your repository, edit files and run commands. They differ mainly in licence, in which models they can use and in how you pay for those models.

We build Neuron, so read this as a vendor's comparison. We kept it to facts each project publishes and link to their pages so you can check them. Plans and prices change; the other projects' own sites are the authority on their terms.

Why people pick Neuron

  • Start at no cost. The Free plan gives hosted LLMs with 100 requests a day and 3M tokens every 5 hours, with no API key to create and no card. See what is free and what is not.
  • Not tied to one model maker. Free models such as GPT-OSS and Qwen, Claude Haiku 5.5 on every plan, Claude Sonnet 5.5 and Claude Opus 5.5 on the paid plans, or your own OpenAI-compatible endpoint. The live model list shows who makes each model and the context it accepts.
  • Open source. MIT-licensed Rust, with the source and releases on GitHub.
  • Familiar controls. Permission modes, an approval prompt (allow once, allow for the session, deny, or deny with a note), a full-screen terminal UI, MCP servers, subagents and headless runs with neuron -p.
  • Simple install. One command: irm https://zero-x.live/install.ps1 | iex in Windows PowerShell, or curl -fsSL https://zero-x.live/install.sh | sh on macOS and Linux. npm and pip work too.

When another tool is the better choice

  • You want the model maker's own agent. If you already pay for Claude or ChatGPT and want the first-party tool built around those models, Claude Code or Codex CLI is the direct route.
  • You need a stable, signed release. Neuron 7.0.0-alpha.5 is an alpha, and its binaries are not code-signed (Windows) or notarized (macOS). Read the known limitations first.
  • You need long context on free models. Free hosted models are shared and some accept fewer tokens per request than their full window. Large repositories may need Pro, Max or your own provider.
  • You want a long track record. Aider, Claude Code and Codex CLI have larger communities today. Neuron is younger and maintained by a small team.

Trying Neuron next to your current agent

You do not have to switch everything at once. Install Neuron, sign in, and give it the same small, checkable task you would give your current agent, such as adding a test and making it pass. Start in read-only mode in a repository you care about, and work on a clean git tree so every change is a diff you can review.

irm https://zero-x.live/install.ps1 | iex

  • macOS / Linux curl -fsSL https://zero-x.live/install.sh | sh

Questions

Is Neuron made by Anthropic?

No. Neuron is built by Zero-X, an independent team in India. Zero-X is not affiliated with Anthropic, OpenAI or the Aider project. Claude is a trademark of Anthropic.

Can Neuron use Claude models?

Yes. Claude Haiku 5.5 is included on every plan, up to 10M tokens a month; Claude Sonnet 5.5 and Claude Opus 5.5 are on the paid plans, billed from included credits. The rest of the Free plan uses free open-weight models.

Can I move my CLAUDE.md or AGENTS.md instructions to Neuron?

Yes, and you do not need to copy them. Neuron reads NEURON.md first and also reads AGENTS.md and CLAUDE.md in each folder from the root down to your project, so your existing instructions work as they are. Run /init only if you want a separate NEURON.md for Neuron-specific rules, and keep each rule in one file so Neuron does not read it twice. The configuration docs list the files Neuron reads.

Neuron CLI: an AI coding agent that works inside your repository

Neuron reads your project, plans a change, edits files and runs your commands, asking before it does anything you have not allowed. Sign in once to use free models through Zero-X, or point it at your own API key.

Neuron 7.0.0-alpha.5 is the fifth alpha, published on 7 November 2026 as a GitHub pre-release. It adds a status bar under the prompt that shows the model, thinking level, folder and branch, permission mode and how full the context is. Expect rough edges; see the known limitations. npm and PyPI serve this release; their old 6.2.0 and 6.2.4 builds are not supported.

What Neuron does

New to coding agents? Read what an AI coding agent is and how its loop works.

Repo-aware agent loop

Neuron explores the files that matter, makes a plan, edits code and checks the result by running your tests or build, then reports what changed.

Built-in tools

Read, write and edit files, search with glob and grep, run shell or PowerShell commands, fetch web pages and keep a task list for longer jobs.

Permission modes

The default is workspace-write; read-only only reads and searches, and danger-full-access is chosen with --permission-mode. Tool calls that need approval ask you: allow once, allow for the session, deny, or deny with a note. Every shell line is classified as a whole.

Full-screen terminal UI

On a terminal, neuron opens neuron-tui with streamed replies, tool calls and their output, a permission dialog, a model picker that greys out unavailable models, and a footer with model, git state, tokens and context. neuron --no-tui keeps the line REPL.

Sessions and resume

neuron --continue reopens the latest chat for this folder in the full-screen UI. The line REPL saves sessions under .neuron/sessions/; continue the newest with neuron --resume latest and shrink long ones with /compact.

MCP servers and subagents

Connect Model Context Protocol servers to give Neuron extra tools, such as a browser, a database or your issue tracker, and hand focused jobs like reviewing a diff to subagents with their own context. Inspect them with /mcp and /agents.

Free models via Zero-X

Sign in with neuron login, approve the code at neuron.zero-x.live/device, and Neuron uses the Zero-X gateway. Provider keys stay on the server; Neuron keeps the login in the macOS Keychain or Windows Credential Manager, or on Linux in ~/.neuroncli/credentials.json, readable only by you.

Bring your own key

Prefer your own provider? Set OPENAI_API_KEY and OPENAI_BASE_URL for any OpenAI-compatible endpoint.

Install

Neuron 7.0.0-alpha.5 is a GitHub pre-release with native binaries for Linux x64 and arm64 (glibc 2.35 or later), macOS on Apple silicon and Intel, and Windows x64 (Windows on Arm runs it under emulation). Pick your system in the menu and paste the command into a terminal: the installer downloads neuron and neuron-tui from GitHub Releases, verifies their SHA-256 checksums and puts neuron on your PATH. The binaries are not code-signed (Windows) or notarized (macOS).

Other ways to install

  • npm (Node.js 22.14 or later): npm install -g @zero-x.live/neuron. On Windows, if PowerShell says “running scripts is disabled on this system”, use npm.cmd install -g @zero-x.live/neuron and run neuron.cmd, or use the PowerShell command above.
  • pip (Python 3.9 or later): python -m pip install --pre neuroncli. Keep --pre: Neuron 7 is a pre-release, and without it pip installs the old, unsupported 6.2.4.
  • From source (needs the Rust toolchain; on Windows the binary is target\release\neuron.exe): 
    git clone https://github.com/RAHUL-DevelopeRR/neuron-v2.git
cd neuron-v2/rust
cargo build --release -p rusty-claude-cli
./target/release/neuron --version

Sign in and run your first task

  1. Sign in from the terminal

    neuron login

    Neuron prints https://neuron.zero-x.live/device and a short code, and opens the link in your browser when it can. Sign in, check that the code matches and choose Approve; the terminal continues on its own. No local port is opened, so this also works over SSH, in WSL and in containers. Neuron keeps the login in the macOS Keychain or Windows Credential Manager, or on Linux in ~/.neuroncli/credentials.json, readable only by you. Sessions last up to 30 days.

  2. Start Neuron in a project

    cd path/to/your-project
neuron

    On a terminal, neuron opens the full-screen UI. It cannot trust a folder yet: run neuron --no-tui in the folder once and press 1 when it asks (or add the folder to trustedRoots in ~/.neuron/settings.json), then restart Neuron. Until then the folder's own settings, hooks and MCP servers are ignored.

  3. Ask for something concrete

    Explain how requests are authenticated in this repo, then add a test for an expired token.

    Use /model to switch models, /permissions to change what Neuron may do, and /usage to see today's limits.

  4. Run it headless

    export NEURON_TOKEN="$ZEROX_API_KEY"   # an nzx_ key from your CI secret store, never committed
neuron -p "Run the test suite and summarise the failures"

    Without a terminal nobody can approve commands, so in the default mode test and build commands are denied and neuron exits with code 2. Allow the commands the job needs in ~/.neuron/settings.json:

    {"permissions": {"allow": ["bash(npm:*)", "PowerShell(npm:*)"]}}

    Put flags such as --model before -p; everything after it is the prompt. --permission-mode danger-full-access allows every call, so use it in disposable environments only. Create an API key in the dashboard for CI or servers without a browser.

Questions

Who sees my code?

The files and messages Neuron includes in a request go to the company serving the model you chose through Zero-X, or to the provider behind your own key. Free tiers of some of these services may use prompts to improve their models and allow human review; the privacy policy names every one. The Zero-X gateway records usage metadata (model, tokens, cost, latency) but is not designed to store prompt or response text. Details are in the privacy policy.

What are the limits?

The Free plan allows 100 requests per day and 1M tokens every 5 hours, 10 requests per minute and 2 at a time. The paid plans (Athlete, Speed, Pro and Max) raise those limits. Daily limits reset at 00:00 UTC; Free's tokens free up 5 hours after they are used. See limits and pricing.

Does it run on Windows, macOS and Linux?

Yes. Release binaries cover Linux x64 and arm64 (glibc 2.35 or later: Ubuntu 22.04, Debian 12, Fedora 36 or newer), macOS on Apple silicon and Intel, and Windows x64; Windows on Arm runs the x64 build under emulation. On older Linux distributions, build from source with Cargo; musl-based Linux such as Alpine is not supported. On Windows, Neuron can also run PowerShell commands.

Can I use Neuron without a Zero-X account?

Yes. Configure your own OpenAI-compatible endpoint with OPENAI_API_KEY and OPENAI_BASE_URL. Signing in to Zero-X is what gives you the free hosted models and the usage dashboard.

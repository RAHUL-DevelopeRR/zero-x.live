Quick start

Install Neuron 7.0.0-alpha.1 (a GitHub pre-release), sign in once with neuron login and approve the short code it shows, then run neuron in any project.

Install on macOS or Linux
curl -fsSL https://github.com/RAHUL-DevelopeRR/neuron-v2/releases/download/v7.0.0-alpha.1/install.sh | sh -s -- --version 7.0.0-alpha.1
Install on Windows (PowerShell)
& ([scriptblock]::Create((irm https://github.com/RAHUL-DevelopeRR/neuron-v2/releases/download/v7.0.0-alpha.1/install.ps1))) -Version 7.0.0-alpha.1
Sign in
neuron login
OpenAI-compatible base URL
https://zero-x.live/v1

API keys

Use an API key to run Neuron in CI or on a server without a browser: set NEURON_TOKEN to the key. Keys can call /v1 and read usage; they cannot manage keys, sessions or billing.

CLI sessions

Each neuron login signs in one device. A session stays signed in while you use it and ends after 30 days without use. Sign out a device you no longer use, or every device at once if a computer is lost or a session token was exposed.

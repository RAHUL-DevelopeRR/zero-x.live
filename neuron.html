Follow the first-use guide

Before you install.

Start with a few documents you know well. You can tell whether a result is useful and check an AI answer against the original.

The app may still show its earlier name, Neuron, in some places. NeuCockpit is the desktop product’s current name.

Indexing comes before search
The app can scan common folders such as Desktop, Documents, and Downloads automatically. Use Add Folder for additional locations. Check the indexing status before testing a search.
Text documents work best
Search supports text extracted from documents, notes, code, PDFs, spreadsheets, and presentations. Extraction varies by file type. Scanned PDFs, images, audio, and video do not provide full content understanding or general OCR.
AI answers need checking
The local model can make mistakes or miss context. Open the source file to check dates, figures, and important conclusions.
Internet access is a choice
Search indexes and model inference run locally. Internet mode is optional and off by default. Downloads, account access, and explicitly enabled internet features need a connection.

Find it. Then work with it.

Use the desktop search panel for files and MemoryOS for questions or summaries.

Describe the document

Search using a phrase about its contents. NeuCockpit compares your query with its local index and returns matching files.

Open the original

Review a result’s filename and location. Open the file in its usual application to verify that it is the document you need.

Summarize locally

Ask the local model to summarize extracted document text. Longer or poorly extracted files may produce incomplete summaries.

Ask in MemoryOS

Use the app’s chat workspace for questions. Retrieval draws on the local index; a relevant source matters more than a confident answer.

For technical users

NeuCockpit uses BGE Small ONNX embeddings, a FAISS/HNSW index, and SQLite metadata. Local generation uses Qwen 2.5 Coder 1.5B Instruct Q4_K_M through llama.cpp. The desktop interface is PyQt6, with a headless neufs command surface.

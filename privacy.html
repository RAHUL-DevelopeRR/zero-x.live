Privacy Policy

Effective date: 3 October 2026.

This policy covers the ZeroX website, account dashboard and connected cloud authentication services for NeuCockpit and NeuronCLI.

Who to contact

For privacy questions, account corrections or deletion requests, email rahultech72216@gmail.com. ZeroX's contact address is 6/2, N. Pugalur, Karur 639113, Tamil Nadu, India.

Information used for sign-in

Signing in with Google gives ZeroX your account identifier and basic profile information, including your email address, name and profile image when available. This information identifies your account and displays your profile in the dashboard. The Google sign-in integration does not request access to Gmail, Drive, Calendar or your contacts.

Email sign-in is handled by Supabase Auth. If you choose another sign-in provider, it supplies the identity and profile information covered by its consent screen. ZeroX does not receive your Google or GitHub password.

Account records and browser storage

Supabase stores authentication records and ZeroX account profiles. Account records include an identifier, profile fields, plan, request and token counters, and account activity timestamps. These records support sign-in, the dashboard and usage limits.

The website stores authentication tokens in secure cookies shared across ZeroX subdomains so you can stay signed in. The cookie lifetime is up to 30 days; token validity is controlled separately by the authentication service. Signing out clears the website's authentication cookies. Some product interfaces also use browser storage for local preferences.

Cloud API sessions can include an account identifier, machine fingerprint, selected provider, plan and usage counters. The configured cloud session lifetime is 24 hours. Account records do not currently have an automatic deletion schedule; contact ZeroX to request deletion.

Local files and cloud AI

Website sign-in does not grant ZeroX access to your computer's folders. NeuCockpit's local search and local AI features process the documents you select on your computer. Cloud AI features have a different data flow: messages and any document text included in a request are transmitted to the selected cloud service. Check the selected mode before submitting private material.

The cloud gateway can route requests to Microsoft Azure AI or Cloudflare AI. Optional OpenRouter authorization connects to OpenRouter. These services process submitted requests under their own policies. Google profile data is used for account functionality; it is not part of the cloud AI request payload constructed by the gateway.

Service providers

Cloudflare hosts the website and API and stores temporary cloud sessions. Supabase provides authentication and the account database. Google and GitHub provide optional sign-in. Website pages can load fonts or scripts from Google Fonts and jsDelivr, which receive the network information needed to serve those resources. Our infrastructure providers may process technical connection information, such as IP addresses, for delivery, reliability and security.

These providers may process information outside India. Their policies govern their own services. Relevant policies: Supabase, Cloudflare, Google, GitHub and Microsoft.

Your choices

You can sign out, clear browser storage and revoke ZeroX's connection in your sign-in provider's account settings. Revoking Google access does not itself delete the existing ZeroX account record. Request account access, correction or deletion by email; ZeroX will need to verify that the request comes from the account owner. Do not send passwords, access tokens or private documents with your request.

Changes

Updates to this policy will be published here with a revised effective date. Questions about a change can be sent to the contact email above.

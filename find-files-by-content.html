NEUCOCKPIT GUIDE · 3 OCTOBER 2026

Find a file when you forgot its name.

Published by Zero-X, the project behind NeuCockpit.

You remember a proposal about an offline search tool. You cannot remember whether its filename says “proposal”, “draft”, or a project code. Searching the document's contents gives you another way to find it.

NeuCockpit is Zero-X's desktop application for semantic file search and local AI. It searches indexed file contents by meaning, so your query can describe the document you need. The examples below are illustrative, not a measured benchmark.

Start with one folder

Download the build for your operating system from the NeuCockpit download page. Choose a small folder containing documents you already know. Let indexing finish before trying a content search. Indexing prepares the files for retrieval; the initial work is separate from subsequent searches.

Describe the contents you remember

Use a concrete topic, task or phrase. For example, try proposal for an offline document search application or notes about setting up Google sign-in. Include context that distinguishes the document from other files in the folder.

A filename search looks for the name you type. Semantic search compares the meaning of your query with indexed content. It can return related documents, so the first result is a candidate to inspect, not a guarantee.

Open the result and verify it

Check the file path and the relevant passage in the original document. If the result is close but wrong, add a distinguishing detail to your query. Local AI can help summarize a retrieved document, but the original file is the source you should use to verify an answer.

If a document does not appear

  • Check that its folder was included and indexing completed.
  • Try a more specific description or a phrase from the document.
  • Check whether the file contains readable text. Scanned pages, encrypted documents and unsupported formats can limit what is indexed.
  • After changing a file, let the app refresh its index before expecting the new contents in results.

What stays local

Local search and local AI run on your computer. Initial downloads, account sign-in and optional internet features need online services. Choose local mode when working with documents you intend to keep on your computer.

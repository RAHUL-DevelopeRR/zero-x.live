A free AI coding agent for your terminal

By Zero-X, the team behind Neuron. Published 5 November 2026.

Neuron is an open-source AI coding agent that works in your terminal like a pair programmer: it reads your repository, edits files and runs your tests or build, and asks before anything you have not allowed. You can start without paying and without a credit card.

"Free" can mean several things for an AI tool, so this page says exactly what is free in Neuron, where the limits are and when a paid plan makes sense.

What is free

  • The agent itself. Neuron is written in Rust and released under the MIT licence. The source code and release binaries are on GitHub, and you can read, change and build it yourself.
  • Hosted LLMs on the Free plan. Sign in with neuron login and Neuron uses free models chosen for coding with tool use, such as GPT-OSS and Qwen, through the Zero-X gateway. The Free plan allows 100 requests a day and 1M tokens every 5 hours.
  • Your own model. Set OPENAI_API_KEY and OPENAI_BASE_URL to use any OpenAI-compatible endpoint instead. Zero-X charges nothing for that; your provider bills you, or nobody does if the endpoint is your own.

What the Free plan does not include

Free hosted models come from shared pools, so we are plain about the trade-offs:

  • Best-effort availability. A free model can be busy or rate-limited. The model list on the homepage shows which models the gateway's health checker last found working, and auto skips models that are busy or failing.
  • Smaller usable context. Some free models accept fewer tokens per request than their full context window. The homepage lists the context each model can actually take on your plan.
  • No Claude models. Claude Sonnet 5.5 and Claude Opus 5.5 are on Pro and Max, billed from the credits those plans include.
  • Alpha software. Neuron 7.0.0-alpha.4 is an alpha. Expect rough edges and read the known limitations. The binaries are not code-signed (Windows) or notarized (macOS).

A pair programmer that runs your tools

Chat assistants write code that you paste and run yourself. A coding agent closes that loop: Neuron searches the repository, plans a change, edits the files, runs your tests and reads the failures until the job is done or it needs your decision. The AI coding agent guide explains the loop in detail.

  • Three permission modes: read-only, workspace-write (the default) and danger-full-access, chosen with --permission-mode. Anything outside the mode asks you first.
  • A full-screen terminal UI, and a line REPL with neuron --no-tui.
  • MCP servers for extra tools, and subagents for focused jobs such as code search or review.
  • Headless runs for scripts and CI with neuron -p.
  • macOS, Linux and Windows, including PowerShell commands on Windows.

Install it free

With Node.js 22.14 or later, npm is the quickest:

npm, any terminal
npm install -g @zero-x.live/neuron

With Python instead, keep --pre while Neuron 7 is a pre-release:

pip, any terminal
python -m pip install --pre neuroncli

Install scripts for macOS, Linux, PowerShell and Command Prompt are in the install options. Then sign in once and start Neuron in a project:

First run
neuron login
cd path/to/your-project
neuron

Questions

Do I need a credit card to use Neuron for free?

No. Install Neuron, run neuron login and sign in. The Free plan needs no payment details.

Which models are free?

Open-weight models chosen for coding with tool use, such as GPT-OSS and Qwen. The current list, with each model's usable context window and live status, is on the Zero-X homepage. Claude models are on Pro and Max only.

Can I use a local model?

Neuron talks to any OpenAI-compatible endpoint set with OPENAI_BASE_URL and OPENAI_API_KEY, so a local server that offers that API can work. The model must support tool calls for Neuron to edit files and run commands.

Is my code used to train models?

The files and messages Neuron includes in a request go to the company serving the model. Free tiers of some of these services may use prompts to improve their models. The Zero-X gateway records usage metadata and is not designed to store prompt or response text. The privacy policy names every company that can receive a request.
